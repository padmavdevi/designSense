Nielsen's 10 Heuristics

DOM and CSS detection · per-check confidence level

10
Reliable H1 System Status — loading states, progress indicators
Reliable H3 User Control — confirmation on destructive actions
Reliable H4 Consistency — button style consistency
Reliable H5 Error Prevention — field types, required indicators
Reliable H6 Recognition — breadcrumb navigation
Reliable H8 Aesthetics — tracked under Accessibility
Needs review H2 Real World Match — technical jargon in UI copy
Needs review H7 Flexibility — search on long lists
Needs review H9 Error Recovery — generic error messages
Needs review H10 Help — password hints, empty state guidance
Reliable = found directly in the page's code — very likely real.  ·  Needs review = matched a common pattern — read it in context before assuming it's wrong.

Accessibility

WCAG-adjacent checks · screen reader & keyboard access

13
Needs review A1 Live Regions — form submits with no aria-live/status
Reliable A2 Heading Structure — skipped levels, multiple H1s
Reliable A3 Keyboard Access — clickable elements missing role/tabindex
Reliable A4 Radio Groups — missing fieldset/legend
Reliable A5 Icon Labels — icon-only buttons missing aria-label
Reliable A6 Field Labels — placeholder used as the only label
Reliable A7 Skip Link — no skip-to-content link found
Needs review A8 Autocomplete — missing on email/name/phone fields
Reliable A9 Color Contrast — WCAG AA text contrast ratio
Reliable A10 Type Scale — too many distinct font sizes
Reliable A11 Color Palette — too many distinct text colors
Reliable A12 Error Association — errors not linked via aria-describedby
Reliable A13 Invalid Fields — aria-invalid with no visible error message

Privacy & Security

Built to be trusted — by design, not just by promise. Audit the source before you drag it.

🔒

Zero network calls

The bookmarklet makes no fetch/XHR requests. Analysis runs entirely inside your browser tab. Nothing is transmitted anywhere.

📖

Open source & auditable

Every line of analysis logic is on GitHub. Read src/bookmarklet.js before you drag it. No obfuscation, no minified blobs.

🛡️

No eval(), no CDN

Fully self-contained. No external libraries loaded at runtime. No dynamic code execution. Static, deterministic JS only.

🎨

Shadow DOM isolated

Our report panel uses Shadow DOM — your page's styles don't affect it and ours don't pollute yours. We never modify your DOM.
